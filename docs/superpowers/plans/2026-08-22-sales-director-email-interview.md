# 영업이사님께 드리는 서면 질문 — AX 체크 질문지·소개서 제작용

> 작성일: 2026-08-22 / 액션플랜 0-2(영업이사 인터뷰)의 서면 대체본
> 용도: 대면·통화 인터뷰가 어려워 메일로 답변을 받는다. 답은 `docs/superpowers/plans/` 아래 답변본으로 저장하고, 질문지 v1(`catalog.ts`)과 소개서 1장의 원천으로 쓴다.
> 답변 목표 시간: 20~30분. 문장으로 쓰지 않으셔도 됩니다 — 단어·키워드 나열로 충분합니다.

---

## 메일 본문 (복사해서 보내시면 됩니다)

이사님, 안녕하세요.

홈페이지에 이사님 영업을 돕는 기능을 만들고 있습니다. 고객에게 카톡이나 메일로 **"소개서 1장 + 3분짜리 진단 링크"** 를 보내면, 고객이 객관식 8문항에 답하는 즉시 화면에 "귀사가 AI로 먼저 바꿀 수 있는 업무 3가지"가 뜨고, 이사님께는 그 고객이 뜨거운 리드인지 자동으로 분류되어 들어오는 구조입니다. 9월 첫째 주부터 실제로 쓰실 수 있게 하려고 합니다.

그 질문지와 소개서를 "우리가 상상한 고객"이 아니라 "이사님이 실제로 만나는 고객"의 말로 만들고 싶어서, 아래 질문에 답을 부탁드립니다. 키워드만 적어 주셔도 됩니다. 모르겠거나 해당 없는 항목은 "해당 없음"으로 넘기셔도 괜찮습니다. 답변은 8/27(목)까지 주시면 일정에 맞출 수 있습니다.

---

### A. 고객이 누구인지 (소개서 첫 줄과 질문 1번에 들어갑니다)

**A-1.** 9월에 먼저 링크를 보내실 만한 회사를 **5~10곳** 적어 주세요. 회사명 대신 "울산 AV 구축 B사"처럼 써주셔도 됩니다. 각 회사마다 괄호 안에 **① 주력 사업(통신/AV/IT인프라/유지보수/복합) ② 대략 인원 ③ 이사님과의 관계(잘 아는 대표 / 담당자만 아는 곳 / 소개받은 곳)** 를 적어 주세요.

**A-2.** 그 회사들에서 이사님이 실제로 대화하는 사람은 주로 누구인가요? (대표 / 영업 임원 / 영업 담당 / 기술 담당 / 경우에 따라 다름)

**A-3.** 10곳 중 "AI 도입"이라는 말에 바로 관심을 보일 것 같은 곳과, "그건 우리랑 상관없는 얘기"라고 할 것 같은 곳은 각각 어디인가요? 그렇게 생각하시는 이유 한 줄씩 부탁드립니다.

### B. 고객이 쓰는 말 (질문지 선택지의 표현이 됩니다)

**B-1.** 이 업계 회사들이 **가장 시간을 많이 쓰는 반복 업무**를 생각나는 대로 적어 주세요. 저희가 초안으로 잡은 것은 아래 6개인데, 빼야 할 것·추가할 것·표현을 바꿔야 할 것을 알려 주세요.
- 제안서·견적서 작성
- 입찰 공고 탐색·서류 준비(나라장터 등)
- 현장 실사 보고·도면·사진 정리
- 유지보수 민원 응대·이력 관리
- 납품·검수·준공 문서
- 거래처 관리·후속 영업 연락

**B-2.** 위 업무들을 고객들은 실제로 **뭐라고 부르나요?** (예: "준공 서류"를 "준공 도서"라고 하는지, "실사"를 "현장 답사"라고 하는지, "유지보수"를 "하자"나 "A/S"라고 하는지) 귀에 익은 표현을 적어 주세요.

**B-3.** 고객사의 업무 자료는 주로 어디에 있나요? (엑셀·한글 파일이 개인 PC에 / 공유폴더 / 그룹웨어·ERP / 카톡·메일에 흩어짐 / 잘 모름) 회사마다 다르면 "대체로 어떻다"로 답해 주세요.

### C. 영업 대화 (소개서 문구와 질문 6~8번에 들어갑니다)

**C-1.** 고객에게 코어디엑스아이를 처음 소개하실 때 **실제로 하시는 말**을 한두 문장 그대로 적어 주세요. 다듬지 않으셔도 됩니다. 말로 했던 그대로가 가장 좋습니다.

**C-2.** 그 말을 들은 고객이 **가장 자주 되묻는 질문 3개**는 무엇인가요? (예: "그래서 얼마예요?", "우리 같은 작은 회사도 되나요?", "직원들이 쓸 수 있나요?", "보안은요?")

**C-3.** 고객이 도입을 망설일 때 **가장 많이 대는 이유**는 무엇인가요? (비용 / 직원 거부감 / 효과 불확실 / 시간 없음 / 기타)

**C-4.** 고객이 AI 도입으로 **기대한다고 말하는 것**은 주로 무엇인가요? (제안·수주 빨라짐 / 인건비·야근 줄임 / 납품 오류 줄임 / 직원 역량 / 신규 서비스 / 기타)

**C-5.** 이 업계에서 도입 결정은 보통 누가, 얼마나 걸려서 하나요? (대표 혼자 즉시 / 대표 보고 후 1~2주 / 분기 예산 때 / 기타)

### D. 도구 사용 (관리자 화면과 알림 방식을 정합니다)

**D-1.** 고객이 진단을 제출했을 때 **어떻게 알림을 받고 싶으신가요?** (메일 / 카톡 / 문자 / 하루 한 번 모아서) 알림 받을 메일 주소도 함께 적어 주세요.

**D-2.** 리드 목록을 보실 때 **꼭 있어야 하는 항목**은 무엇인가요? (회사명·담당자·연락처·등급·제출일 외에 필요한 것 — 예: "내가 보낸 날짜", "다음 연락 예정일", "메모")

**D-3.** 고객에게 링크를 보낼 때 **주로 쓰는 채널**은 무엇인가요? (카톡 / 문자 / 메일 / 명함 뒤 QR) 채널에 따라 소개서를 이미지로 만들지 PDF로 만들지가 달라집니다.

### E. 소개서 1장 (이사님이 들고 다니실 자료입니다)

**E-1.** 소개서에 **꼭 들어가야 한다**고 생각하시는 것 3가지와, **절대 넣지 말아야 한다**고 생각하시는 것 1가지를 적어 주세요.

**E-2.** 고객에게 보여줄 만한 **레퍼런스**로 언급해도 되는 곳이 있나요? (회사명을 써도 되는지, "울산 제조 A사"처럼 익명으로 써야 하는지도 함께)
