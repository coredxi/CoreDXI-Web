| 회사 | 업종 | 규모 | 관계 |
|---|---|---|---|
| 서울 IT인프라 A사 | IT인프라·통신 | 30명 | 대표와 오래된 친분(자주 소통) |

### A-2. 주로 대화하는 상대
대표 70%, 영업·기술 총괄 임원 30%. 결정권자와 직접 소통(Q8 도입결정구조 문항 설계와 정합).

### A-3. 반응 예측
- 관심 높음(A사, D사): 제안·견적 작업량 많아 야근 심함 — 업무 과부하 해결이 시급한 상황
- 관심 낮음(C사): "현장 출동·기계 위주라 AI 쓸 일 없다"는 고정관념 강함 → 첫 멘트에서 반박 필요

**1-11 첫 링크 발송 우선순위 제안**: A사·D사(관심 높음) 우선, C사는 인트로 멘트로 고정관념 완화 후 발송 검토.

## B. 고객이 쓰는 말 (Q3 반복 업무 문항 반영 대상)

### B-1. 반복 업무 — 기존 6개 항목 적절, 2개 항목 추가
- 추가: "하자보수/정기점검 보고서 작성"
- 추가: "감리·시공 체크리스트 정리"

### B-2. 현장 실무 용어 (카탈로그 라벨 교체 대상)
| 기존 초안 용어 | 실제 고객 용어 |
|---|---|
| 제안서·견적서 | 견적, 내역서, 투찰 서류 |
| 입찰 공고·서류 | 나라장터, 적격심사 서류 |
| 현장 실사 | 현장 답사, 현장 사진/보고서 |
| 유지보수 | A/S, 하자보수, 월정기 점검 |
| 납품·검수·준공 | 준공 도서, 검수 서류, 완공계 |
| 거래처 관리 | 영업 롤링, 바이어 관리 |

### B-3. 업무 자료 보관 위치
영엗·기술 담당자 개인 PC(엑셀·한글) + 현장 카톡방에 파편화. 그룹웨어 있어도 서류는 각자 보관.
→ Q5(데이터 위치) "scattered" 선택 비중이 높을 것으로 예상, "데이터 정리 1주" 분기가 자주 트리거될 전망.

## C. 영업 대화 (소개서 0-4 / /ax-check 인트로 반영 대상)

### C-1. 첫 소개 문구
> "대표님, 요즘 제안서 쓰고 나라장터 서류 챙기느라 직원들 밤새죠? 그거 AI로 하루 만에 끝내게 해주는 시스템 나왔습니다. 일단 3분짜리 진단만 한번 해보세요."

### C-2. 자주 되묻는 질문 Top 3
1. 비용 — "그래서 이거 한 달에 얼마 들어갑니까?"
2. 사용성 — "우리 현장 엔지니어들이 나이가 좀 있는데, 쓸 만큼 쉽습니까?"
3. 보안 — "우리 회사 단가표나 도면 정보가 외부로 유출되진 않나요?"

### C-3. 도입 주저 이유
비용 부담 + "우리 업종 특수 업무에도 진짜 효과가 있을까?" 하는 불확실성

### C-4. AI 도입 기대 효과
제안·투찰 속도 단축 → 수주량 확대, 엔지니어 야근·문서 업무 감소

### C-5. 도입 결정 방식·소요 시간
대표 단독 결정 80%+, 결심하면 1~2주 내 즉시 도입 (Q7 "3개월 내"/Q8 "제가 결정합니다" 조합이 HOT 등급 다수 예상)

## D. 도구 사용 (관리자 화면 요구사항, 0-3~0-7 범위 밖 — 별도 백로그로 분리)

- D-1. 진단 제출 알림: 카톡 실시간(필수) + 하루 1회 종합 메일 요약. 메일 주소 `sales_lead@company.com`(플레이스홀더로 보임 — 실제 SALES_NOTIFY_EMAIL은 이미 0-5에서 `devcoredxi00@coredxi.com`로 확정됨, 카톡 알림은 미구현 신규 요구사항)
- D-2. 리드 목록 필수 항목 추가 요청: 링크 발송일, 열람/제출 시각, 대표/담당자 구분, 특이사항 메모란
- D-3. 링크 전달: 카카오톡 90% — 카드뉴스형 이미지 + 클릭 시 Web/PDF 연결 구조 선호

→ D-1(카톡 알림)·D-2(리드 목록 필드 확장)는 `/admin/leads` 개선 백로그. 카톡 알림 연동은 별도 설계 필요(카카오톡 비즈니스 API 또는 알림톡) — 이번 0-3~0-7 범위 밖, Phase 2 후보로 별도 등록 권장.
