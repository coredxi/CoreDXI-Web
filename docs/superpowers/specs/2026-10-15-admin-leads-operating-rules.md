## 1. 등급별 대응

| 등급·상황 | 누가 | 무엇을 | 기한 |
|---|---|---|---|
| **HOT** | 영업이사 | 전화. "상세 진단 메일 예정" 날짜에 T1 메일이 나간 뒤(오전 10시대 발송) "오늘 오전에 보내드린 진단 메일 보셨어요?"로 시작 | T1 발송 당일 |

## 2. 상태·메모 갱신

- 전화 후 영업이사가 `/admin/leads`에서 상태를 **"연락함"**으로 바꾸고 영업 메모 한 줄을 남긴다.
- 상태 값: 신규 → 연락함 → 미팅 → 종료.
- T1 메일은 시스템이 예정 시각에 자동 발송한다. 보낼 필요가 없거나 고칠 내용이 있으면 발송 전에 리드 상세의 팔로업 메일 패널에서 보류·본문 수정·즉시 발송한다.

## 3. 주간 점검 (매주 월요일, 기술이사)

다음 두 경우 영업이사에게 카톡으로 알린다.

1. HOT 리드가 T1 발송 후 1영업일이 넘었는데도 상태가 **"신규"**로 남아 있는 경우 → 1절 "HOT 대행"에 따라 기술이사가 대신 연락
2. 영업 메모에 적어 둔 다음 액션 날짜가 지난 경우

- 이 수동 점검이 'SLA 미이행 감지 자동 알림'을 대신한다(알림 코드는 만들지 않음, 2026-10-15 결정).
- 4주 운영 뒤에도 누락이 생기면 자동화를 다시 검토한다.

## 4. 테스트·개인정보 정리

- 내부 테스트 제출(`ref=internal-test` 등)은 확인이 끝나면 리드 상세의 **"삭제(개인정보 파기)"**로 지운다. 지우지 않으면 T1 메일이 실제로 발송된다.
- 상단 **"테스트 데이터 정리"** 버튼은 자동 테스트(E2E: `ref=e2e` + 회사명 `[E2E TEST]`)가 남긴 데이터만 지운다. 내부 테스트 리드는 지우지 않는다.
